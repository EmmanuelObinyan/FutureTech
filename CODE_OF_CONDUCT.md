# Code of Conduct

## Our Pledge
We want FutureTech to be a welcoming, respectful space for everyone contributing 
to this project — regardless of experience level, background, or how small or 
large their contribution is.

## Expected Behavior
- Be respectful and constructive in code reviews, issues, and discussions.
- Welcome questions from teammates who are less experienced with Git, React, 
  or the codebase — everyone started somewhere.
- Give feedback on code and ideas, not on people.
- Assume good intent. If something in a PR or issue seems off, ask before assuming.
- Keep discussions focused and on-topic within issues and pull requests.

## Unacceptable Behavior
- Personal attacks, insults, or dismissive comments toward a contributor.
- Harassment of any kind, public or private.
- Deliberately submitting harmful, malicious, or plagiarized code.
- Ignoring or overriding a teammate's reviewed and agreed-upon work without discussion.

## Scope
This applies to all project spaces — GitHub issues, pull requests, commit 
messages, and any related team communication (e.g. WhatsApp/Discord group 
tied to this project).

## Enforcement
If a contributor violates this Code of Conduct, the project maintainer 
(Emmanuel Obinyan) will address it directly with the individual first. 
Repeated or serious violations may result in removal as a collaborator.

## Reporting
If you experience or witness unacceptable behavior, reach out directly to 
Emmanuel Obinyan, either privately or by flagging it in the relevant issue/PR.
